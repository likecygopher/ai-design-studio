# 变更规格：i18n 第二批（管理端运维页 + 任务/成本页）

- 变更 ID：`CHG-2026-10-27-I18N-ADMIN`
- 在 `CHG-2026-10-27-I18N` 基础上继续，覆盖平台日常运维高频页面。

## 覆盖范围

- `/admin` 系统概览：标题、状态条、统计卡、快捷入口、告警标题/严重度。
- `/admin/jobs` 任务管理：状态/审批/用户筛选、表格列、待审批徽标、批准/驳回/重试/取消提示、分页。
- `/admin/plans` 套餐管理：列表、表单、删除确认、提示。
- `/tasks`（任务中心）：标题、状态筛选、空态、错误/重试、状态/类型标签、进度/时间/编号/失败原因、等待审批、取消/重试/加载更多。
- `/costs` 资源消耗：标题、预算进度、维度汇总、明细表头、空态、单位汇总。
- 任务状态/类型字典统一为 `job.status.*` / `job.type.*`，供管理端与用户端复用。

## 行为

- 默认中文；英文通过 cookie 切换后服务端/客户端同步。既有中文测试全部保持不变。
- 管理端告警的 `message` 仍由服务端返回中文（告警 id 稳定，后续可按 id 映射英文）。
- 未覆盖：`/admin/users`、`/admin/ai`、`/admin/audit`，以及 13 个工作流页面（第三批）。
