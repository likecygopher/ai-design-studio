# 变更规格：中英双语（i18n 基础设施 + 壳层/认证/账户）

- 变更 ID：`CHG-2026-10-27-I18N`
- 触发：已批准清单第 5 项「国际化中英切换」。平台面向海外团队，原 UI 为中文硬编码。
- 状态：基础设施完成；壳层、登录/注册、账户设置已双语；管理端与工作流页面按轮次继续迁移（见 §5）。

## 1. 架构（无新增依赖）

- `src/i18n/core.ts`：语言列表（`zh`/`en`）、cookie 名 `studio_locale`、`translate(locale, key, params)`、`{name}` 插值、缺失键回退中文；字典同时导出类型。
- `src/i18n/server.ts`：Server Component 通过 `await cookies()` 读取 `getLocale()`。
- `src/i18n/I18nProvider.tsx`：客户端 Context；无 Provider 时默认中文（兼容既有测试与嵌入组件）。
- `src/components/LocaleSwitcher.tsx`：`中文 / EN` 分段按钮；写入一年期 SameSite=Lax cookie 后 `router.refresh()`，服务端重新渲染并同步 `<html lang>`。
- 根布局 `app/layout.tsx`：异步读取 locale，`<I18nProvider>` 包裹全站，`lang` 随语言切换。

## 2. 覆盖范围（本批）

- 应用外壳：工作区 aria、角色/退出、异步模式提示、语言切换器。
- 主导航：首页、任务中心、创作中心/资产中心/品牌管理与全部子项、平台管理五项。
- 登录/注册：标题、字段、按钮、错误提示（含两步验证码字段）、注册校验主流程文案。
- 账户设置：账号信息、修改密码、两步验证（开启/恢复码/停用）、登录设备（当前设备/最近活跃/吊销）。

## 3. 行为

- 默认 `zh`；未知 cookie 值回退 `zh`。
- 切换语言不改变 URL，不触发登出；服务端内容通过 `router.refresh()` 更新。
- 日期/时间仍按浏览器本地格式显示；服务端返回的业务错误消息目前为中文，后续按错误码映射（P2）。
- 少量设备名称（浏览器/系统）与注册校验细节文案仍为中文，属于下一批迁移范围。

## 4. 验收

1. 登录页右下角可切换 `中文 / EN`，切换后标题、字段、按钮与提示为英文，`<html lang>` 同步。
2. 登录后外壳与主导航随语言切换（Home / Task Center / Admin / AI Engines…）。
3. 账户设置四个卡片全部双语。
4. 默认中文，既有无 Provider 的组件测试继续通过。
5. `tsc` 0；113 测试文件 / 682 测试；`next build` 0；Playwright 6/6（含英文切换）。
