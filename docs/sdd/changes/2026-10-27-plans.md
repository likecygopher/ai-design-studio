# 变更规格：套餐（Plan）配额

- 变更 ID：`CHG-2026-10-27-PLANS`
- 触发：已批准清单第 10 项中的「计费/订阅」基础切片（不含支付网关）。
- 目标：管理员定义套餐并绑定用户，按套餐统一月度预算与并发上限，作为订阅计费前的配额模型。

## 1. 数据

```prisma
model Plan {
  id                 String  @id @default(cuid())
  name               String  @unique
  description        String?
  monthlyBudgetUnits Int?    // null=平台默认；0=不限
  maxActiveJobs      Int?    // null=平台默认
  users              User[]
}
User.planId String? // onDelete: SetNull
```

- 迁移：`20261027090000_plans`。

## 2. 配额解析

- 月度预算优先级：**用户显式预算**（0=不限）> **套餐预算**（0=不限）> **平台默认**（`DEFAULT_MONTHLY_BUDGET_UNITS`）> 不限。
- 并发上限：套餐 `maxActiveJobs` 优先于平台 `MAX_USER_ACTIVE_JOBS`；未绑定或为 null 时使用平台默认。
- 入队仍执行预算/并发校验，超限返回既有 429 错误码。

## 3. 管理端

- `/admin/plans`：套餐列表（名称/描述/预算/并发/用户数）、新增/编辑（弹窗）、删除（仍有用户时 409）。
- `/admin/users` 编辑弹窗新增「套餐」下拉；列表资源列展示套餐名。
- 接口：`GET/POST /api/admin/plans`、`PATCH/DELETE /api/admin/plans/{id}`；审计 `admin.plan_create/update/delete`。
- 导航「平台管理」新增「套餐管理」。

## 4. 验收

1. 创建套餐并绑定用户后，用户预算/并发按套餐生效；用户显式覆盖优先。
2. 套餐有成员时删除返回 409；解绑后可删除。
3. 管理端套餐页可增删改；E2E 管理端页面检查包含 `/admin/plans`。
