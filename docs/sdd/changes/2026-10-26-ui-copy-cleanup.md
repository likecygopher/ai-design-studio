# 变更规格：界面文案产品化（去说明文字）

- 变更 ID：`CHG-2026-10-26-UI-COPY-CLEANUP`
- 触发：用户反馈"界面上的说明文字像原型草图，需要产品视角"
- 原则：**界面只承载操作与状态，不承载产品介绍、教学步骤与免责声明**；说明性内容下沉到文档/帮助。

## 1. 文案分层原则

| 类型 | 处理 | 示例 |
|---|---|---|
| 页面级介绍段（这是什么/能干什么） | **删除** | "存储和管理产品信息…决定后续所有生成功能的输入" |
| 营销式卖点/子弹列表/装饰性英文眉标 | **删除** | "多用户隔离 + 异步生成任务"、`PRODUCT STICKER COMPOSITOR` |
| 教程式步骤说明 | **删除** | "两张图片缺一不可…"、"智能选区适合颜色连续的区域…" |
| 模型免责声明 | **删除**（遵守平台使用条款即可） | "辅助生成说明：AI 会根据参考图补全视角…" |
| 表单约束 | **保留，压缩为一行** | "8 位以上，含字母与数字。"、"PNG / JPEG / WebP ≤30 MB" |
| 状态/计数/进度 | 保留 | "已选 3 个角度"、"0/6 已生成" |
| 校验错误/危险操作警告 | 保留 | "当前密码不正确。"、"不能禁用或降级当前登录的管理员账号。" |
| 空态/加载态 | 保留（可点击行动） | "暂无素材，可在上方上传。" |
| 折叠帮助（`<details>`） | 保留，默认收起 | "参考图规则 · 0/3" |

## 2. 本轮清理范围

- 认证页：登录/注册删除品牌营销段、功能列表、页脚说明与眉标；仅保留品牌锁定、标题、表单与"创建账号/去登录"。
- 平台页：用户管理/账户设置/任务中心移除副标题说明；弹窗提示压缩为一行约束；删除弹窗的统一英文眉标。
- 页面头：素材库、产品档案、Icon Design、手机图标准化、SKU 替换、POP、白底图、多语言、成本页、产品视频移除介绍段与装饰性英文标签；成本页改名为"资源消耗"并本地化表头，补充空态。
- 工作流面板：风格迁移、多语言、POP、白底图、手机图、SKU、素材库清理教程式提示与免责声明；保留约束、计数、状态与空态。
- 共享组件：`StudioDialog` 移除每个弹窗顶部的 `AI CONTENT STUDIO` 装饰标签。

## 3. 验收

1. 页面不再出现产品介绍/教程段落；仅保留标签、状态、短约束、错误与空态。
2. 所有既有测试通过（未断言被删文案；密码规则提示断言已同步更新）。
3. 登录/注册/管理/账户/工作流页面视觉层级不塌陷，空态与表单仍可用。
4. `typecheck` + 全量测试 + 生产构建全绿；Playwright 巡检 13 个主要页面无 console/page error。
