## 剩余工作（建议顺序）

1. **i18n 收尾**：13 个工作流页面；语言偏好写入用户设置（当前仅 cookie）。
2. **对象存储 driver**：抽象资产写入/读取/删除与清理为 `StorageDriver`（local/s3），支持 S3 兼容端点、SigV4、私有读取/预签名、清理列举；多副本部署必需。
3. **组织多租户（团队）**：`Organization/Team` 模型、成员与角色、资源归属、跨用户共享素材、管理员分权；需要全表 `orgId` 与迁移策略，工作量最大。
4. **模板市场**：模板/素材包模型、审核与上架、克隆到工作区、收益/授权（依赖组织与计费）。
5. **计费订阅**：用户明确**不需要**支付/订阅账单；保留 `Plan` 套餐配额（预算/并发/绑定用户）作为额度模型，不再新增订阅/发票。
6. **Webhook 完善**：管理 UI、Token scope、投递记录 UI、指数退避重试已完成；剩余：事件扩展（job.cancelled、budget.blocked）。
7. **API Token 权限**：按 scope 限制路由（当前令牌继承完整角色）、每令牌限流与用量统计。
8. **可观测性深化**：告警 Webhook 外发已完成；剩余：多副本聚合、CSP nonce、Sentry/OTel。
9. **平台加固**：Webhook DNS rebinding 防护/出口代理、Redis 故障演练、数据库备份与恢复演练、审计保留策略。

## 已知限制（当前版本）

- 配置生效：AI 供应商/审批开关等以数据库为准；Worker 即时刷新，Web 进程最多 60s 收敛（多副本）。
- 指标为进程内注册表，重启清零；多副本需逐实例抓取。
- Edge middleware 登录预限流仍为进程内；最终登录/接口限流在 Node 层可用 Redis。
- 预算校验基于已发生用量（非预留），极端并发下可能小幅超限。
- 2FA 恢复码仅展示一次；管理员无法替用户重置 2FA（需用户用恢复码或联系运维）。
- 数据导出每类最多 1000 条；任务 payload 不包含在导出中。
- 删除账号时资产文件尽力删除，剩余孤儿由 `pnpm cleanup` 处理。
- 本地存储为 `public/` 卷；生产多副本必须共享卷或等待对象存储 driver。
