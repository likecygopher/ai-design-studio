# 变更规格：工作台双布局模式（舒适 / 紧凑）

- 变更 ID：`CHG-2026-10-27-COMPACT-LAYOUT`
- 背景：现有玻璃拟态 16:9 工作台视觉表现好，但任务/数据密集页面可用操作区域不足；增加接近 Open WebUI 的高密度布局，同时保留原舒适布局。

## 1. 交互

- AppShell 右上角、首页工具区新增「舒适布局 / 紧凑布局」切换按钮（`WorkspaceLayoutToggle`）。
- 偏好写入 `localStorage["studio-layout"]`，跨页面、刷新、同浏览器标签页同步（`storage` + 自定义事件）。
- 默认保持原「舒适布局」，不影响甲方设计师偏好的既有视觉。

## 2. 紧凑模式

- 工作台占满视口（`100vw × 100dvh`），去除 16:9 比例、圆角、边框、玻璃模糊与阴影；
- 侧栏收窄（AppShell 212px / 首页 196px），导航与品牌间距压缩；
- 主内容背景改为浅灰实色、内边距缩小，顶部预留 54px 避让布局/设置浮层；
- 首页内容改为纵向 flex：入口卡拉伸填充剩余高度，快捷工具固定在下方，底部信息贴底；
- 所有业务页面（任务中心、创作 Studio、管理端等）复用 AppShell，即自动获得更大操作区。

## 3. 舒适模式

- 保持原玻璃工作台、背景图、16:9 舞台、侧栏 246px、较大留白与 blur/saturate 效果。

## 4. 验收

1. 切换后立即生效并持久化；刷新/跳转页面保持选择；两种模式互不影响业务功能。
2. 紧凑模式下页面无浮层遮挡（顶部工具避让），首页填满视口。
3. 门禁：tsc 0；135 测试文件 / 790 测试；next build 0；E2E 10 passed（含切换与持久化断言）。
